# Reader 직접 탐색·사전 강조 전환 (2026-11-03)

## 변경

- 읽기 도구 모음의 `미리보기·북마크` 버튼으로 페이지 그리드를 바로 연다.
  각 페이지의 별표로 북마크를 추가·해제하고 `북마크만` 필터를 사용한다.
  저장된 페이지를 열면 기존 북마크의 위치·확대율로 이동한다.
- `문서 목차`는 별도 버튼으로 바로 연다. 기존 3개 탭 경유는 제거했다.
  현재 읽는 페이지를 저장하는 도구 모음 북마크 버튼도 유지한다.
- 강조 버튼은 기본 `커서를 올릴 때만 강조`와 `사전 단어 항상 강조`를 전환한다.
  항상 강조에서는 커서가 없어도 사전에 매칭되는 표현을 표시한다. 텍스트 선택,
  뜻 팝업, 확대·축소와 스크롤은 그대로 사용한다. 모드는 Reader 화면 세션 동안
  유지하며 사전 데이터에 기록하지 않는다.
- 기존 PDF 좌표 변환과 긴 표현 우선 사전 매칭을 재사용한다. PDF 뷰어가
  화면 주변에 유지하는 페이지의 텍스트만 불러오며, 문서 전체 자동 분석은 없다.
  문서·사전 변경 및 비동기 결과의 순서가 뒤바뀌었을 때 이전 결과를 버린다.
- 북마크 키와 단어 데이터는 그대로 사용한다. 패키지·서버·AI·OCR 추가는 없다.

접근성 표현에 맞게 선택자를 수정했다. 안내 화면 자체는 스크린샷으로 확인했다.

이전 Windows 전체 테스트의 PDF 네이티브 C++ 도구 체인 부재는 그대로다.
전체 테스트와 Android 빌드는 Linux CI에서 확인하고 실제 기기 결과와 구분한다.
기존 영구 서명 배포 APK를 갱신하는 작업은 포함하지 않는다.

강조되지 않을 수 있다. 강조가 없다는 사실만으로 사전에 없다고 단정하지 않는다.
복사 제한은 기존 처리대로 존중하며, 스캔 PDF의 OCR은 제공하지 않는다.
