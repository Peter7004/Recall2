# P3 페이지 북마크·문서 탐색 검증 (2026-11-03)

## 구현

- 페이지 별표로 현재 페이지·페이지 내 상대 위치·확대율을 저장한다. 페이지당
  하나의 북마크를 유지하고 이동할 때 현재 보기 모드는 유지한다.
- 문서 탐색에서 내 북마크, PDF 내장 목차, 페이지 미리보기를 제공한다.
  목차가 없는 PDF에는 안내를 표시한다. 목차의 목적지 API가 이동에 실패하면
  해당 페이지로 이동하고 정확한 위치 대신 페이지로 이동했음을 알린다.
- 미리보기는 활성 탭의 보이는 셀만 생성한다. 출력은 최대 160×210 픽셀,
  렌더 작업은 동시에 두 개로 제한하며 취소와 이미지 해제를 처리한다.
  문서 전체 및 PDF 엔진의 메모리 사용량까지 제한한다는 의미는 아니다.
- 별도 키 `recall.reader.pageBookmarks.v1.<문서 SHA-256>`을 사용한다.
  손상된 북마크는 오류를 알리고 덮어쓰지 않는다. 문서 삭제 시 읽기 기록과
  페이지 북마크를 정리하며 삭제 실패 시 둘 다 복원한다.
- 원본 PDF·단어 데이터·단어 북마크·플래시카드는 변경하지 않는다.
  새 패키지, AI, OCR, 서버 및 최소 SDK 변경은 없다.

제어된 PDF는 기존 매뉴얼의 복사본으로 생성했다. 원본은 수정하지 않았다.
`tool/make_reader_outline_fixture.py`가 목차 있는/없는 5쪽 PDF를 생성한다.
`tool/reader_document_navigator_smoke.cjs`로 실제 브라우저 검증을 재현한다.
처음에는 목차 없음 안내의 자동화 선택자가 실패했으나 화면은 정상이었다.
Flutter의 aria-label을 확인하도록 선택자를 수정한 후 전체 검증이 통과했다.

500페이지 탐색 UI 테스트는 가상 위젯 테스트이며 실제 500페이지 PDF를
열거나 Android 메모리를 검증한 결과가 아니다. 웹 결과와 APK 빌드 결과를
Android 실기기 성공으로 해석하지 않는다. GitHub 전체 테스트·빌드 상태는
HANDOFF.md에 정확한 커밋과 실행 번호로 기록한다.
