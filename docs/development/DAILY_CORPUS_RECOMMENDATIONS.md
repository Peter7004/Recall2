# 오늘의 추천 단어 — 교재·논문 학습 방향

홈 ‘오늘의 목표’에서 교재 중심 / 논문 초록 중심을 선택한다.
기존 날짜별 임의 단어 표시와 알파벳순 기본 학습을 같은 추천 목록으로 연결했다.
선택한 기준은 기본 학습 탭에도 적용되며, 기존 명시적 모음/북마크/개별 카드 학습은 유지한다.

## 추천 기준

1. 선택 자료에서 잠정 채택 DF가 양수인 단어를 대상으로 한다.
2. 학습 제외한 카드와 오늘 이미 학습한 카드는 추천하지 않는다.
3. 미학습 단어를 먼저 보여주고 해당 자료의 DF 내림차순, TF 내림차순으로 정렬한다.
4. 복습 단어는 마지막 학습일이 오래된 것부터, 같은 날이면 DF·TF순으로 정렬한다.
5. 동일 점수는 용어 표기/카드ID로 결정해 목록을 안정적으로 유지한다.
6. 오늘 학습 목록은 남은 일일 목표만큼만 가져온다. 방향 변경은 학습 횟수를 초기화하지 않는다.

교재와 초록의 빈도를 합치지 않고, 의미 보류 건수도 추천에 넣지 않는다.
통계 자체가 없거나 선택 자료에서 관측된 학습 대상이 없으면 기존 전체 단어 학습으로 돌아간다.
통계는 있으나 오늘 해당 용어를 모두 학습한 경우에는 완료 상태를 표시한다.
통계 미제공/0인 개인 단어도 기존 사전·모음 등에서 계속 학습할 수 있다.

## 저장·호환성

선택은 별도 기기 설정 `recall.learning.corpus-source.v1`에
`textbook` 또는 `abstracts`로 저장한다. 미설정/잘못된 값은 교재 중심이다.
저장 실패 시 기존 선택을 유지하고 다시 선택할 수 있도록 안내한다.
이 기기 설정은 기존 단어·학습 기록 JSON 백업의 범위에 추가하지 않았다.

`recall.data.v3`, Reader 저장소,13열 사전 CSV,834개 기본 용어, 카드ID,
우선순위, 북마크와 학습 기록의 저장 형식은 변경하지 않았다.
새로운 DB/패키지/AI API/간격 반복 알고리즘을 도입하지 않았다.
기준을 바꾸면 기본 학습 세션만 새 순서로 준비하며 명시적으로 선택한 학습 범위는 유지한다.

## 수정 파일

- `lib/recall_store.dart`: 기기 설정, 관측 후보/정렬, 목표 적용, 당일 중복 제외.
- `lib/ui/recall_dashboard.dart`: 선택 칩, 추천 단어와 해당 자료의 DF·TF 근거.
- `lib/main.dart`: 기본 학습 목록 연결 및 방향 변경 시 기본 세션 갱신.
- `test/daily_corpus_test.dart`: 정렬/관측/제외/일일 목표/선택 유지/실패/모바일/명시적 학습 보존.
- `tool/daily_corpus_smoke.cjs`: 실제 웹 데이터/추천과 학습 순서/재실행 보존.
- 버전/README와 개발 인계 기록.

## 원형 그래프 UI — 로컬 변경, 미배포 (2026-11-11)

추천 단어 아래 두 자료별 등장 문서 비율(DF/전체 자료 수), DF와 TF를 표시한다.
예: Voltage 교재21/22=95.5%, 초록107/639=16.7%. 교재/초록의 TF를 합치거나
두 비율을 100%짜리 구성 비율로 해석하지 않는다. 중요도/정확도 점수도 아니다.
선택 기준은 테두리와 텍스트로 표시한다. 작은 화면에서는 두 자료 카드를 세로로,
넓은 화면에서는 나란히 표시한다. 문서 수가 없으면 원을 그리지 않고 미제공으로 안내한다.
통계가 없는 용어는 그래프를 숨기며, 보류 용례는 분자와 추천에 포함하지 않는다.

UI의 ‘잠정’은 ‘문맥 필터 적용 · 보류 제외’로 바꿨다. ‘집계 기준’에서는 자동 규칙
판정이며 전체 인적 검수는 아니라는 사실, 자료 중복 가능성, 초록/본문 차이를 명시한다.
내부 basis=provisional_accepted와 통계/보류 원본은 변경하지 않았다.
직접 확인: 기존 재집계 Excel의 ‘출현 근거 표본’, ‘용어별 규칙’, ‘문서 목록’,
‘방법과 검증’. 검증 ZIP의 occurrences.jsonl에는 전체 출현 위치/문맥/판정이 있다.
검수 자료를 열어볼 수 있다는 사실만으로 의미 정확도가 검증된 것은 아니다.
