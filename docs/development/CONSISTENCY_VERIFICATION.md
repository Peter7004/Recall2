# S2 — 정의와 원문 링크 일관성 검증

2026-11-03. 학습 우선순위 P1의 첫 모듈이며 Reader 백업은 포함하지 않는다.

## 변경한 동작

- Reader 목록의 용어·주 뜻·영어 정의·한국어 설명은 현재 로딩된 사전 항목이
  있으면 모두 해당 항목에서 가져온다. 빈 최신 필드를 과거 값으로 채우지 않는다.
- 항목이 없으면 저장 당시 스냅샷 전체와 명시적 안내를 표시한다. 저장 스냅샷,
  사전/학습 데이터 및 키는 조회 때문에 변경하지 않는다. 같은 앱 사전 변경을 구독한다.
- 공통 DocumentRepository.availableDocumentIds가 정상 메타데이터와 관리 파일
  존재 여부를 검사한다. 손상 메타데이터/누락 파일/개별 접근 검사 오류는 제외한다.
  한 파일 오류 때문에 다른 정상 출처를 모두 숨기지 않는다. 파일 전체를 읽지 않는다.
- 학습 목록과 사전/플래시카드 출처 화면이 같은 판정을 사용한다. 이동 직전에도
  다시 검사하고 실제 열기 실패를 안내한다. 중복 이동 클릭을 막는다.
- 저장소 생성 실패는 재시도 때 다시 생성할 수 있다. 학습 출처 문서 ID를 한 번에
  수집해 파일 존재 검사를 위해 단어별 전체 출처를 반복 탐색하지 않는다.

구분한다. GitHub 정확한 SHA 전체 테스트/빌드/배포 결과는 완료 후 추가한다.

## 범위와 재현

- 파일 존재 검사는 원문 전체 무결성/암호 해제/렌더링 성공을 보증하지 않는다.
  검사 이후 다시 사라지는 파일은 실제 open 오류로 처리한다.
- 다른 탭의 사전 편집을 자동으로 전부 동기화하는 기능은 아니다. 새로 로딩한 사전과
  현재 앱 인스턴스 변경을 기준으로 하며 저장 당시 데이터를 자동 갱신/삭제하지 않는다.
- 브라우저 테스트는 새 disposable context만 수정한다. 사용자 실제 저장소는 건드리지 않는다.
- test/reader_consistency_test.dart 및 tool/reader_consistency_smoke.cjs 참조.
  RECALL_PLAYWRIGHT_MODULE과 RECALL_READER_TEST_URL로 테스트 런타임/주소 지정.
- 초기 브라우저 자동화의 뜻 exact-text 탐색은 Flutter의 합쳐진 의미 노드 때문에 실패했다.
  스크린샷에서 올바른 표시를 확인하고 합쳐진 접근성 텍스트를 검사한 뒤 통과했다.
