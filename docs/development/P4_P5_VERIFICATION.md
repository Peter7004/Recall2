# Reader 안정성·단어 저장·원문 복귀 (2026-11-03)

## 구현 범위

- 손상된 PDF 메타데이터를 항목별로 격리한다. 정상 문서 목록·열기는 유지하고
  손상 항목은 안내한다. 손상 기록·PDF를 자동 삭제하거나 덮어쓰지 않는다.
- 미리보기 별표 갱신 중 기존 그리드·스크롤·썸네일을 유지한다.
- 강조 상태를 대기/분석 중/매칭 완료(0 포함)/텍스트 읽기 불가/오류로 구분한다.
  오류에는 명시적 재시도를 제공한다. 복사 제한·이미지 전용 페이지를 구분한다.
- 선택한 사전 단어를 저장한다. 카드 ID별 학습 항목과 문서 내 등장 위치를
  분리하고 동일 문서·페이지·문자 시작/끝 위치의 중복을 막는다.
- 출처에는 문서 내용 SHA-256, 제목, 페이지, 실제 선택 원문·주변 문맥,
  정규화된 PDF 조각 좌표와 문자 범위를 저장한다. 문자열 재검색으로 위치를
  추측하지 않는다. 같은 단어의 서로 다른 등장 위치는 각각 보존한다.
- 저장 위치는 초록색으로 표시한다. Reader 단어 목록에서 원문으로 이동하고
  이동 전 읽던 위치로 돌아갈 수 있다. 기존 사전 상세·플래시카드에도 PDF 학습
  출처 화면을 연결했다. 원문 이동은 설치된 pdfrx의 컨트롤러 API를 재사용한다.
- PDF 삭제는 학습 항목과 문맥을 지우지 않는다. 삭제되거나 손상된 문서로의
  이동은 비활성화한다. 사전 카드가 삭제돼도 저장 당시 뜻·정의 스냅샷을 유지한다.
- 기존 단어 북마크 연동은 켜기만 하는 멱등 연산이다. 반복 저장으로 해제되지
  않는다. 실패 시 메모리와 SharedPreferences 캐시를 복원한다. Reader 출처 저장과
  기존 북마크 쓰기는 다른 저장소이므로 부분 실패를 별도로 안내한다.
- 뜻 팝업에 영어 정의를 표시하고 Reader 강조/기본 보기 설정을 기억한다.

## 저장 및 데이터 보호

- `recall.reader.learning.v1`: 단어 스냅샷·출처를 단일 JSON 스냅샷으로 저장.
  직렬 쓰기 후 성공한 상태만 화면에 반영한다. 손상된 데이터를 빈 목록으로
  덮어쓰지 않는다. 대기 중 저장은 화면 종료 후에도 완료할 수 있다.
- `recall.reader.settings.v1`: 표시 설정. 기존 진행도·페이지 북마크 키는 유지.
- `recall.data.v3`: 사용자가 단어 저장을 요청한 항목의 북마크 활성화만 의도적으로
  변경한다. 용어 뜻·정의·원본 데이터는 변경하지 않는다. CSV 해시 불변 확인.
- 서버, AI, OCR, 신규 앱 패키지, 최소 SDK 변경 및 파괴적 마이그레이션 없음.
